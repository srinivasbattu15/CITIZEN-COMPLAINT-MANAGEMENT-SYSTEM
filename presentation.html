Abstract & Problem Statement

❌ Problems in Traditional Redressal

  • Lack of Transparency: No status visibility for citizens after submitting.
  • Manual Routing: Paperwork delays transferring complaints between departments.
  • No SLA Enforcement: Unaddressed issues remain pending without escalation.
  • Lack of Proof Verification: No proof confirming if repairs were fixed.

✅ Proposed CCMS Solution

  • Transparent Portal: Unique Complaint ID & live timestamped timeline.
  • AI Smart Routing: Natural Language NLP auto-routes to departments.
  • GIS Map Heatmap: OpenStreetMap coordinates and complaint heatmaps.
  • Proof Verification: Mandatory Before vs. After photos by officers.
  • Civic Rewards: Reward points redeemable for municipal vouchers.

Project Objectives & Scope

Objective 01

Citizen Empowerment

Provide an intuitive web portal for citizens to report street defects, potholes, sewage, and streetlight issues.

Objective 02

Automated SLA Engine

Use AI text analysis to auto-classify categories, set SLA deadlines (6h to 48h), and trigger escalation alerts.

Objective 03

Field Officer Accountability

Equip department officers with task queues, GIS location maps, and mandatory proof photo uploads.

Objective 04

Public Performance Analytics

Equip municipal administrators with real-time KPI dashboards, resolution graphs, and PDF/CSV exports.

Technical Innovations

🤖 AI Smart Complaint Classifier

NLP algorithm analyzing title & description to auto-suggest department category & priority level with confidence scoring.

📍 Interactive GIS Location Heatmap

Leaflet OpenStreetMap rendering status-coded pins (Emergency, In Progress, Resolved) and draggable location marker.

📸 Photo Pin Annotator

Click-to-annotate spot tool over uploaded images allowing citizens to tag exact defect spots (e.g. '2ft Deep Pothole Trench').

🏆 Civic Gamification Engine

Citizen reward points (+50 PTS report, +100 PTS resolution, +25 PTS rating) redeemable for Metro passes & municipal tax vouchers.

Technology Stack

Frontend Tier

React 18, Vite 6, Tailwind CSS, Lucide Icons, Recharts, Leaflet Maps, Canvas Confetti

Backend API Tier

Node.js, Express.js REST API with CORS middleware & Multer file upload storage

Database Store

Embedded JSON / SQLite persistent engine with automated indexing & seed loading

Reporting & Document Export

jsPDF & HTML2Canvas PDF report generator + CSV audit exporter

Database Schema & Entities

Users Table: id (PK), name, email, role, points, badges, rewardsRedeemed
Complaints Table: id (PK), title, description, category, departmentId, priority, status, lat, lng, imageUrl, photoAnnotations, slaDeadline
Departments Table: id (PK), name, code, slaHours, head, activeComplaints
Timeline Audit Table: complaintId (FK), status, note, timestamp, updatedBy
Rewards Catalog: id (PK), title, category, costPoints, code, description

Key UI & Live Demonstrations
